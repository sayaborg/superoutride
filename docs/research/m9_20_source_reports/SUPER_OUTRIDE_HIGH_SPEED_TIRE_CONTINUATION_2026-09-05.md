# SUPER OUTRIDE — 高速ドリフト／ポストピーク再検証・続報

2026-09-05。read-only research。**未リリース。以下の試作はrepositoryの新しい権威ではない。**

## 1. 結論

前回提案した「ポストピークの負勾配上限から遷移幅を決める」案を、力の釣合い・入力を合わせ直した比較へ進めた。単なる幅拡大では高速側の問題を解消できなかった。勾配を小さくしても、不安定な角度帯が別の角度へ移る例を確認した。

一方、**横方向の容量を高く、縦方向の容量を低くした楕円形の合力上限と、ポストピーク落差なしの組合せ**では、新しい到達経路を確認した。Testarossa、ENG3、横容量係数3.00、縦容量係数0.75、横ピーク位置8%の隔離試作で、通常の前進状態からブレーキなしで150/200 km/h付近の15→25→15度往復が成立した。左右・60/120/240 Hzを確認した。

さらにプレイヤー舵入力0.35を固定し、アクセル0.20→0.65の一段階変更だけでも、約184.7 km/h・14.4度へ到達した。ただし入口は最大約21.8度を通る。これは同一モデルの実行結果であり、手操作フィールの保証ではない。

**大角度での入力感度は未解決。** 25度付近で舵・アクセルに±0.02を1秒加えると、無誤差実行との差が最大約9.1度に達した。したがって「高速／大角度への到達と角度往復の候補」は得たが、「人間が容易に扱える製品タイヤ」の合格判定はしていない。

## 3. 勾配上限案の実験

現行の純横滑りピークG、ピークスリップP、深い滑走係数Sを保ち、横滑りの遷移幅を

```
W = max(P, 1.5*(G-S)/L)
```

にする。Lは純横滑りの正規化力に対する最大負勾配を制限する実験定数であり、新しい採用済みの設計値ではない。既存の飽和関数H、荷重比例、力の向き、車輪Ωから独立した倍率は維持する。

L=1/2/4/8/16と現行を比較した。54 km/hのG1.2/P8/S1、150/200 km/hのG3/P8/S2・G4/P8/S2について、各13角度の釣合いを探索（6モデル×5条件×13角度=390試行）。**未収束は解の不存在を意味しない。** 制御範囲外の根や出力不足も、利用可能なドリフトと数えない。

### 観測した問題

G4/P8/S2、200 km/h、車体角12度の釣合いでは、現行の最大局所増幅率は約−0.149/s。L16へ変更し、その曲線で釣合う入力を求め直すと、約+7.629/sへ変わった。15度の釣合いは両方とも約−0.114/sだった。

L16では滑走台地の開始が横スリップ0.16から0.2675へ移動する。12度の後輪は新たに落差の途中へ入り、15度の後輪は台地上に残る。**負勾配を小さくするだけでは、不安定帯を別の角度へ移してしまう場合がある。**

さらにL8以下の高G断面では、今回の多初期値探索で10〜15度付近の利用可能な釣合いを見つけられないケースが多かった。これは不存在証明ではない。しかし以前より大きな後輪横力が残るため、必要な前輪力と荷重配分も変わる。純横滑りの曲線の見栄えだけで合格にはできない。

通常初期運動からの固定舵・アクセルpulseも各64条件、現行/L8/L16の3モデルで比較した。今回の限定されたG4/P8/S2/ENG3条件では、目標速度帯の深い維持への成功は0件だった。最大角度も約3度で、ここではそもそも深いポストピーク域へ入っていない。**この結果を「アクセル進入一般が不可能」と一般化しない。**

証拠: `slope-eq-*.json`, `slope-stability-*.json`, `entry-*.json`。

## 4. 代替の構成則: 単調な摩擦楕円

前後共通の一つの法則を使う。縦横の初期剛性Cは同じまま、飽和判定のノルムだけを変えた。

```
Dx = C*sx
Dy = C*sy
F0 = muY * N
eta = muX/muY
rhoE = hypot(Dx/eta, Dy) / F0
F = (Dx,Dy) * H(rhoE)/rhoE
```

ゼロ需要ではF=0。Hは既存のradial C1関数。そのため線形域でF=D、飽和域では

```
(Fx/(muX*N))^2 + (Fy/(muY*N))^2 <= 1
```

となる。両成分へ同じ非負倍率を掛けるので、力は元の滑り需要方向のまま。**横需要に応じて摩擦係数を落とす追加倍率は使用しない。** 試作では既存のS/Gを1にすることでその経路を無効化した。

主要候補:

```
muY = 3.00
muX = 0.75
eta = 0.25
Py = 0.08
K = 1.26*3/0.08 = 47.25
Px = eta*Py = 0.02
ENG = 3
D12 / M60 / ACT0.25
```

これは実車タイヤの測定値ではない。**縦横容量比4:1という強い異方性を許したゲーム向け構成則の検証**である。前後・車種別の特例はない。容量異方性と初期剛性異方性は別であり、今回は後者を追加していない。

eta=0.25/0.30/0.50/0.70と、等方・落差なしを比較した。代数方程式の根が出ても、舵範囲外やエンジン出力不足なら利用可能とはしない。eta=0.50の探索はログ出力で非有限engineMinを丸めようとして一度停止したため、出力を修正して再実行した。初回の停止を物理モデルの失敗と扱わない。

従来の「異方性の48条件で持続0件」とは、曲線・較正・入力が一致する再現試験ではない。今回は落差を無くし、各モデルの釣合いに合わせて入力を再計算している。異方性一般の可能性を否定できないことを示す結果である。

## 5. アクセルだけで高速の定常ドリフトへ到達

Testarossaを通常の200 km/h前進、横速度0、yaw rate0、rack0で初期化。以後の状態上書きなし。

```
0–5 s:   player steering=0.35, throttle=0.20, brake=0
5–80 s:  player steering=0.35, throttle=0.65, brake=0
80 s以降: 通常のrate-limited中立へ解放
```

60Hz・正方向では踏み増し直前は約189.3 km/h・2.52度の通常旋回。その後最大約21.65度を経て、65〜80秒平均で**184.67 km/h・14.414度**、角度変動幅約0.00019度へ到達した。長時間保持は収束確認であり、プレイヤーが80秒必要という意味ではない。10〜15秒区間（踏み増し5〜10秒後）にも角度は14度台、速度は180km/h台後半にある。

左右・60/120/240Hzの6条件で再現。rear lock、unsupported、brake input tick、積分エラーは0。実ラック角は既存の進行方向自動舵で変わる。**一定なのはプレイヤー舵入力で、ラック固定ではない。** ギア固定なし。中立解放後にも小さいβ・yaw rateへ戻った。

準備時から舵0.33/0.35/0.37、踏み増し後throttle0.63/0.65/0.67の9条件では、末尾平均のβは約10〜15.7度、速度は約163〜239 km/h。全て滑りは残るが、同じ速度・角度を保つわけではない。これを9条件全て「同等の操縦性」と数えない。

証拠: `throttle-verified.json`, `throttle-*.json`, `throttle-margins.json`。

## 6. 普通の入力から15→25→15度

## 7. 大角度での操作誤差: 未合格

200km/hの25度区間へ実際に到達した状態を分岐コピーし、舵とTHにそれぞれ−0.02/0/+0.02を加えた。分岐コピーは独立比較のためで、途中で人工的な釣合いへ補正していない。

### 20秒間保持した場合

- u/THとも−0.02: 最後の5秒平均は約3.3度・274km/h。意図せず退出。
- THだけ+0.02: 約31.2度・183km/h。
- u/THとも+0.02: 約35.4度・159km/h。

「±2ポイントで25度・200km/h付近を保つ」は不合格。

### 1秒だけ誤差を加えて戻した場合

無誤差の同時刻実行との差で評価した。

- 最初の1秒で最大約7.54度。
- その後の過渡を含めると最大約9.09度。
- 20秒時点では全9条件の角度差が約0.21度以内へ戻るが、速度差は最大約2.5km/h残る。

**局所的に戻れることと、短い誤操作に鈍感であることは別。** この試作を人間に扱いやすい完成品とは呼ばない。

証拠: `correction-margins.json`, `short-errors.json`。`assert_findings.mjs`は成功結果だけでなく、この退出・過敏さの反例も消されていないことをチェックする。

## 8. なぜ過敏なのか: 摩擦楕円上の勾配

後輪が飽和した固定荷重の楕円上では

```
dFy/dFx = -(muY/muX)^2 * Fx/Fy
```

200km/h・25度の釣合いでは、後輪のFxは縦容量muX*Nの約92.9%。上式は約−10.04となる。**固定Nで縦力を100N増すと、横力は局所的に約1000N減る**向きである。これは車体全体でのTH-to-betaゲインそのものではなく、その上流にあるタイヤ力配分の微分。

今回、ポストピークの負勾配による入口の不安定さを回避しても、縦容量近くで大きくなるcombined-slipの入力感度は残った。次に調べるべきは、この容量消費率、前輪修正余力、後輪車輪回転の過渡、THと舵を組にした角度・速度応答である。「TCSを入れればよい」とはまだ結論しない。

証拠: `ellipse-control-sensitivity.json`。比較研究として、Stanford Dynamic Design LabのHindiyeh(2013)とGoh/Goel/Gerdes(2019)は、後輪駆動力の速度・横運動への二重作用と車輪回転の重要性を論じる。ただし本試作の性能証明は上記本番ソルバの実験による。

## 9. 速度・半径・出力の限界は残る

候補の200km/hでの釣合い:

| β | 軌跡半径 | 速度方向に垂直な加速度 | 必要車輪供給出力 |
|---:|---:|---:|---:|
| 15度 | 約158.2m | 約1.99g | 約440kW |
| 25度 | 約203.9m | 約1.54g | 約548kW |

これは平坦路の定常釣合い解析。150/200km/h入力往復の時系列と混同しない。円の累積軌跡長も、実コースでの有用な前進距離の証明にはしない。**25度で200km/hを保てても、R30mやR100mをそのまま200km/hで通れるわけではない。**

新しい容量則も滑走損失を消さない。25度の約548kWのうち約459kWがタイヤ滑り損失。このためENG3は依然必要だった。エンジンの増強が不要になったという結果ではない。

## 10. 低速加速と制動への影響

同じG3/P8、ENG3、平坦路、DIRECT入力で比較。両方とも横ポストピーク落差なし。

| 項目 | 等方の基準則 | 楕円候補(muX=.75,muY=3) |
|---|---:|---:|
| 0–100km/h | 約1.57s | 約5.57s |
| 最大観測前後加速度 | 約2.44g | 約0.61g |
| 200→100km/h 全制動 | 約1.87s | 約3.55s |

タイヤ容量によって低速の駆動力は抑えられるが、**制動側も同じ縦容量に制限される。** TCSや低ギア専用トルク上限を加えていない。最大観測値は荷重移動・抗力等を含む離散時系列であり、純粋なmuX*gと同一ではない。

muY1.2に同じetaを掛ける別の診断ではmuX=.3になり、0–100が約16.1sだった。したがってetaだけを既存全較正へ機械的に掛けて公開してはならない。

## 11. 数値・構造の確認

候補について、3つのG×4荷重×3路面係数×7横スリップ×201縦スリップ=50,652サンプルを検査。

- 摩擦楕円内（最大二乗和1.0000000000000007、丸め誤差範囲）。
- 滑りの正仕事0。
- 固定横スリップでFxが縦スリップに対し非減少。
- N=0の力0。
- 荷重2倍で縦横力とも2倍。

Hが非減少であるため、固定接地条件では変更後もFx(Ω)は非減少。既存のG*Nを使った車輪残差のbracketは保守的な上限として残る。これは以前の「postpeakを合成スリップへ移して複数根を作る」変更とは異なる。

位置・絶対yawの対称性を除いた10状態の局所行列も60/240Hzで比較した。変速点を跨ぐ全域証明ではない。連続釣合いと離散定常状態の差も残るので、実際の通常入力シミュレーションを主な到達証拠とする。

基準版の全テスト後に再ビルドされた164個のJSも、Pages配布物と再照合して不一致0件だった（`final-validation.json`）。

この研究での確認は基準版659件と候補専用の力・到達・感度検査。旧G/P/S・2P契約の回帰を黙って変更して候補が全件通ることにしていない。

## 12. 次の設計判断

1. 固定2Pを単純に長くする／勾配上限を付ける案は、今回の高速条件で本命にはできない。
2. 単調な摩擦楕円は、高速・大角度の到達を確認できた比較候補として残す。ただし強い異方性、低い制動容量、大角度の過敏さを伴う。
3. 次の比較は、25度付近の縦容量消費率と入力感度を下げながら、前輪余力・旋回半径・必要出力を維持できるか。無理ならプレイヤー入力から操舵・駆動への変換も明示的設計判断として対象にする。
4. 採用するとしても既存曲線へ項を積み重ねるのでなく、負勾配のあるS軸を残す必要があるかを問い直す。縦容量・横容量・初期剛性という3特性に置き換える設計も可能だが、旧Sの意味を黙って流用しない。権威文書・型・compiler・回帰の更新が必要。
5. all-nine、人間のタッチ／キーボード、高速実コース、有用なコーナー前進距離は未検証。新しい初期設定として公開しない。

**今回得たのは、現在の車体ソルバと入力経路のまま、タイヤ構成則の変更で高速のアクセル進入と15→25→15度を成立させられるという証拠。そして、落差を取り除いてもcombined-slipの大角度感度が残るという次の失敗条件である。**


## 13. 保存観測の解釈

`lib.mjs`の`fq/rq`は既存の等方合力上限に対する観測ノルム比を残した診断欄である。楕円候補では方向にも依存するため、これを実際の`lateralPostPeakScale`の倍率と解釈してはいけない。主要候補はS=Gなので、そのポストピーク倍率自体は常に1。力、slip、容量楕円、散逸はそれぞれの欄と専用検査から評価する。

`models/L0p5`は再生成スクリプトにある追加比較用の構成であり、今回の390試行には含めていない。保存ログ・成功件数を未実行の候補へ拡張しない。
