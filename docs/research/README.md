## Interpretation rules

- Each report names its measured source/build and input conditions. Later filenames or a green
  complete suite do not silently upgrade a historical experiment to a current product guarantee.
- Browser tire calibration and stock construction/rival reference are different. Material grip
  factor is a multiplier, not the final tire coefficient. Do not compare unnamed configurations.
- `completed` means the diagnostic's finite observation window ended without its stop condition.
  It does not mean stable yaw, sufficient correction margin, road-width compliance or useful drift.
- Distances on the broad plane are trajectory distances, not useful distance along a real corner.
  Speed-qualified beta avoids a stopped-vehicle angle being called a moving spin.
- Neutral natural flight, torque-caused lift, support infeasibility, suspension overtravel and
  gameplay recovery are different observations. Do not rename failure-reporting tests as passes
  of the underlying maneuver or make diagnostics recover silently to obtain a clean trace.
- The two CSVs retain primary compact inventories. Reports retain selected additional observations
  and reproduction definitions, not every old full-precision or 20 Hz trace. Session ZIPs are NOT
  required restart dependencies. Regenerate primary output using the tools in this repository;
  do not claim a missing historical artifact has been recovered merely because it is reproducible.

## Reproduction from a fresh checkout

Use the locked Node24 environment and build first. The following output files are generated by the
commands, not pre-existing input files the next worker needs to obtain:

```sh
npm ci
npm test
node tools/torque-protection-probe.mjs --hz 120 --out protection.json
node tools/torque-protection-terrain-probe.mjs --hz 120 --out terrain-browser.json
node tools/torque-protection-terrain-probe.mjs --hz 120 --calibration stock --out terrain-stock.json
node tools/braking-yaw-probe.mjs --hz 120 --out braking-primary.json
node tools/braking-yaw-probe.mjs --id VFR750R --capture --out vfr-traces.json
node tools/braking-yaw-probe.mjs --apply-mode DIRECT --out braking-direct.json
```

Run only the comparison needed for the next question; do not repeat the complete historical survey
as a startup ritual. M9.25 resumes player tire calibration; front/rear specialization remains deferred. Brake
capacity/bias provenance, real-browser HUD acceptance and combined-input handling remain separate
open tasks in the current handoff. Any physical or control change needs its own Decision Gate.

New evidence must name the exact source, conditions and observation limits, preserve counterexamples,
and link back here when it becomes relevant. Do not overwrite released validation files or original
research reports to make their terminology match a later implementation.
