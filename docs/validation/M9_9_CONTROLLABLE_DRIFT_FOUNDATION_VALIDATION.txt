1. Release scope

M9.9 deliberately changes only three coupled handling assumptions:

- preserve M9.7's exact unit-coefficient travel-direction steering law and zero-DC washout;
- replace the shared preset-1 normalized tire stiffness pair 9.0 / 10.5 with axle-neutral
  9.75 / 9.75;
- replace M9.7's both-held-sign deep-beta self-recovery release criterion with explicit
  recovery-input controllability.

The governing product rule is:

  Uncontrollable slide is forbidden. Controllable drift is allowed.

No drift mode, drift assist, target sideslip, travel-direction gain, alternate tire law, new
dynamic state, CAR/BIKE branch, drive-layout branch, TCS/ABS, roll DOF, handbrake, clutch,
renderer, camera, route or topology change is introduced. Handling remains DEV_UNCALIBRATED.
