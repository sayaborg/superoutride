# SUPER OUTRIDE　コースと基準中心線の対応表

公称周長は、手本にした実在GPの競技記録・公認値。中心線平面周長は、収録JSONの直線と円弧の合計（0.01 m表示）。FL2のITALYとMONACOには、指定されたROMの直線を反映した正本を収録する。両コースのファイル名は手本の年代を示す。各JSONの原点（データの始点）は、その配置のスタートライン（推定）。

高低差（JSONの `elevation_m`）は、一周の走路の最高点と最低点の標高差。累積上昇量や立体交差の高さとは別の量である。「地形推定」は旧線上の後年の地形測量値、「旧・現地形」は大改修前後の標高資料の比較、「後年公表」は共通区間を持つ後年の実在コースの公表値。「部分推定」は失われた区間を含む一周の暫定値。各JSONの `elevation_basis` に採用理由を記載した。

## スタートラインの補足

各JSONの原点は、その配置のスタートライン（推定）。根拠と、2026-11-07版の原点からの距離（`previous_origin_to_start_m`）は各JSONの `start_finish_basis` に記載した。どの配置も、線のある直線や通りは確かだが、その上の位置の確度は低い。後年の値を使った配置は、線の位置が当時から変わっていないという前提に立つ。
