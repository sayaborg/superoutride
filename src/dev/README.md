# Regression inputs and diagnostics

`fixtures/` contains minimal finite worlds and image inputs consumed by tests or tools.
`diagnostics/` contains read-only probes. Product composition loads saved `content/courses` and
`content/images`; it imports neither directory. Repository hygiene checks enforce these boundaries.

The straight world preserves mechanics/audio/sprite inputs. The curved neighborhood and rising
straight preserve steering, contact, recovery and render-height regressions. Stadium geometry,
height, material and fixed paint/scenery inputs preserve the projection and framebuffer oracles.
They carry no route execution, streaming or production catalog authority.
